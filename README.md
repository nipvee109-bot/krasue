# กระสือวัดร้าง v2

เกมผีเล่นกับเพื่อน 2–6 คนบนเบราว์เซอร์ คอมกับมือถือเล่นห้องเดียวกันได้ ไม่มีขั้นตอน build เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ก็เล่นได้เลย
ของเดิม (v1) เก็บไว้ที่ `v1.html`

## โหมด
- **ปกติ**: ทุกคนรู้ว่าใครเป็นผี ผีเริ่มในโบสถ์ คนหนีได้ 15 วิไปซ่อน
- **ปลอมตัว**: ผีถูกสุ่มตอนเริ่ม ยืนปนอยู่กับทุกคนในร่างของตัวเอง (คุยได้ ส่องไฟได้) กดตะครุบเพื่อกลายร่างออกล่า 22 วิ แล้วกลับมาปลอมตัวใหม่ เบาะแส: เทียนที่มันจุดไม่ขึ้น, ข้ามเส้นน้ำมนต์ไม่ได้, ตาแดงตอนฟ้าแลบ, อีกาบินหนี, ตะกรุดสั่นเมื่อมันอยู่ใกล้, ปาเกลือใส่จะบังคับให้เผยร่าง ประตูวัดเปิดเมื่อไหร่ร่างปลอมหลุดถาวร

## มือถือเต็มจอ
- Android: แตะจอครั้งแรกเกมจะขึ้นเต็มจอและล็อกแนวนอนเอง (มีปุ่ม "เต็มจอ" ในเมนู)
- iPhone: Safari ไม่ให้เว็บเต็มจอ ให้กดแชร์ → "เพิ่มไปยังหน้าจอโฮม" แล้วเปิดเกมจากไอคอน

## เล่นในเครื่องตัวเอง
**ง่ายสุด (Windows):** ดับเบิลคลิก `play.bat` ในโฟลเดอร์นี้ จะเปิดเกมให้ 2 แท็บ (แท็บแรกกดสร้างห้อง แท็บสองกดเข้าห้อง) ปิดหน้าต่างดำเมื่อเลิกเล่น ไม่ต้องลง Python

หรือใช้ Python:
```
cd ruean-rang
python -m http.server 8002
```
แล้วเปิด http://localhost:8002/krasue/ (ใช้ค่า "krasue" ใน `.claude/launch.json` ได้เหมือนกัน)
- เปิดหลายแท็บในเบราว์เซอร์เดียวแล้วเติม `?local=1` ท้ายลิงก์ จะเล่นกันเองได้โดยไม่ต้องใช้เน็ต (ไว้ทดสอบ)
- `?debug` เปิดตัวช่วยทดสอบ (เริ่มเกมคนเดียวได้ และมี `window.__game`)
- `?touch` บังคับปุ่มมือถือบนคอม, `?quality=low|medium|high` บังคับคุณภาพภาพ

## ขึ้น GitHub Pages (ได้ https ซึ่งมือถือต้องมีถึงจะใช้ไมค์ได้)
1. เข้า github.com แล้วกด **New repository** ตั้งชื่อเช่น `krasue` เลือก **Public** แล้วกด Create
2. ในหน้า repo ที่ว่างอยู่ กด **uploading an existing file** แล้วลาก *ของข้างใน* โฟลเดอร์ `krasue` ทั้งหมด (`index.html`, โฟลเดอร์ `css`, `js`, ไฟล์ `README.md`, `v1.html`) ลงไป แล้วกด **Commit changes**
3. ไปที่ **Settings → Pages** ตรง Source เลือก **Deploy from a branch** เลือก branch `main` โฟลเดอร์ `/ (root)` แล้วกด Save
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/krasue/`
5. แก้เกมรอบหน้า: อัปโหลดไฟล์ที่เปลี่ยนทับในหน้า repo แล้ว Commit อีกครั้ง

## ถ้าเพื่อนบางคนต่อเข้าห้องไม่ได้
เน็ตมือถือบางค่ายบล็อกการเชื่อมต่อแบบ P2P ต้องเพิ่ม TURN server (สมัครฟรีได้ที่ metered.ca หรือ Twilio) แล้วใส่ใน `js/net.js` ตรง `K.ICE.push(...)` ที่มีตัวอย่างไว้

## ไฟล์
| ไฟล์ | ทำอะไร |
|---|---|
| `js/core.js` | ค่าตัวเลขของเกม (`K.CFG`), ข้อมูลผี 3 ตัว (`K.GHOSTS`), ของขลัง, ชุดแต่งตัว |
| `js/render.js` | renderer, คุณภาพภาพ + วัดความเร็วเครื่องตอนเปิดครั้งแรก, texture, แสง (แบ่งไฟจริงให้เทียนที่ใกล้ที่สุด) |
| `js/map.js` | แมพวัด, กุฏิ/โบสถ์ที่เปรตเข้าไม่ได้, ศาลพระภูมิ, จุดสุ่มเทียน/ของไหว้/ของขลัง, การชน |
| `js/models.js` | ตัวละครพร้อมชุด, กระสือ ผีปอบ เปรต, วิญญาณ, ของในฉาก, หน้าผีตอนตกใจ |
| `js/audio.js` | เสียงทั้งหมด (สังเคราะห์สด ไม่มีไฟล์เสียง) |
| `js/net.js` | PeerJS + โหมด `?local=1` |
| `js/voice.js` | เสียงคุยตามระยะ (ไม่เกิน 15 ม.) และกติกาใครได้ยินใคร |
| `js/host.js` | โฮสต์คุมเกม: ห้องรอ, คิวผี, ภารกิจ, ตะครุบ, ไฟฉาย, ของขลัง, สกิลผี, ฟ้าสาง |
| `js/client.js` | ข้อมูลฝั่งผู้เล่นแต่ละคน, เหตุการณ์ในเกม, เอฟเฟกต์ |
| `js/play.js` | การเดินของตัวเอง, วงจังหวะจุดเทียน, ท่าทางผู้เล่นอื่น, แสงและเสียงต่อเฟรม |
| `js/ambience.js` | หมอกพื้น, ฟ้าแลบ, พระคลุมผ้า, ธงตะขาบ, ผีพราย, ความกลัวตอนผีใกล้, ร่างหลอนตอนอยู่คนเดียว |
| `js/input.js` | คีย์บอร์ด, เมาส์ (ล็อกเมาส์ ถ้าไม่ได้จะเปลี่ยนเป็นกดค้างแล้วลาก), ปุ่มมือถือ |
| `js/hud.js` | เมนู, ห้องรอ, แต่งตัว, ตั้งค่า, HUD |
| `js/main.js` | วนเฟรม |
