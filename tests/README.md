# ชุดทดสอบ regression

ชุดทดสอบนี้เปิดเกมหลายแท็บในเบราว์เซอร์ headless ตัวเดียว แล้วเล่นห้องจริงผ่านโหมด `?local=1` (BroadcastChannel ไม่ต้องใช้เน็ต) จากนั้นตรวจว่าโฮสต์กับลูกห้องทุกคนเห็นสถานะเดียวกัน
ตัวเกมไม่ต้องเปิด `?debug` เพราะเทสต์อ่านและแก้ค่า `window.K` จากข้างนอกเอง

## วิธีรัน
```
npm i -g playwright            # ครั้งแรกครั้งเดียว (หรือ npm i playwright ในโฟลเดอร์นี้)
npx playwright install chromium
python -m http.server 8002     # รันที่โฟลเดอร์หลักของ repo
node tests/regress.js          # รันทุกกรณี
node tests/regress.js escape voice   # รันเฉพาะบางกรณี
```
- `KRASUE_URL` เปลี่ยนที่อยู่เกม (ค่าเริ่มต้น `http://localhost:8002/`)
- `KRASUE_LIBS` โฟลเดอร์ที่มี `three.min.js` กับ `peerjs.min.js` ใช้แทน CDN เวลาเครื่องต่อ CDN ไม่ได้
- `KRASUE_JSON` บันทึกผลเป็นไฟล์ JSON

ผลแต่ละกรณีออกมาเป็น PASS หรือ FAIL ถ้ามีกรณีไหนไม่ผ่าน โปรแกรมจะจบด้วย exit code 1

## ข้อจำกัด
- ทุกแท็บอยู่ในเครื่องเดียวกันและไม่ผ่าน PeerJS/WebRTC data channel จริง (ยกเว้นเสียงคุย ซึ่งใช้ RTCPeerConnection จริงกับไมค์ปลอม)
- กรณีที่ต้องพึ่งเวลาจริงจะช้าลงในเครื่องที่วาดภาพด้วยซอฟต์แวร์ จึงตั้งเกณฑ์ไว้หลวมๆ
- กรณี `disguise_*` ดักข้อความดิบที่แต่ละแท็บได้รับ (ผ่าน BroadcastChannel ของ `?local=1` และ `K.clientRecv` ของโฮสต์) แล้วตรวจว่าไม่มีอะไรบอกตัวผีปลอมตัว ทั้งใน payload และใน state ของหน้าเว็บ
- โฮสต์เห็นข้อมูลทั้งหมดเสมอ (เป็นคนรันเกม) เทสต์จึงตรวจเฉพาะสิ่งที่ส่งถึงลูกห้อง
